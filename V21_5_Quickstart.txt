V21.5 固定母池策略工作台：安裝與使用

重點：母池研究不再每次執行。固定規則後，修改權重只測策略；不下載行情，不重選母池。
固定的是 ADV200 之類的規則，各月仍用當時的前200檔，不是拿今天名單回測過去。
現有證據還沒有證明唯一最佳母池。手動固定是研究範圍，不是獲利保證。

1. 先暫停舊任務，備份 data/ 和 V21_DATABASE.zip。
2. V21.4 可覆蓋修正包；版本混雜使用完整包。入口維持 app.py，不刪 data/ 或 Secrets。
3. 預設開啟「固定母池策略」。已有資料不必再啟動全市場下載。
4. 選已完成的資料任務，按「登錄這份資料」。若資料遺失，到「資料準備與備份」還原自己的 V21_DATABASE.zip。
5. 固定一個母池規則，例如三個週期都用 ADV200。也可依舊訓練結果分別指定，但不用最後保留期的贏家來選母池。
6. 在畫面策略 JSON 調整因子與權重，按「快速測試」。每策略最多4個因子，權重總和1。其他未改策略會重用快取。
7. 先看 profile_comparison_5/20/60.csv 和 REPORT.txt。這是開發比較，不是每次都發布一份新盲測。
8. 假說與參數確定後，才按一次「凍結確認」。同一或重疊的最後持有期間不允許換權重反覆開答案。

書中原則的模型化
- 心理與資金：價量只是代理變數，不是貨幣供給或真實持有人心理。
- 逆向：先有較大回檔，再觀察止穩，不是感覺便宜就買。
- 過熱與恐慌：先比較不加濾網與加濾網的差異，不先假定減碼有效。
- 紀律：無槓桿、初始單檔配置上限10%、記錄假說、保留失敗結果。
- 十律十戒的轉譯是本系統的研究規範，非原書逐條原文。詳見 KOSTOLANY_DESIGN.md。

重要限制
新因子首次需讀本機日線建立快取；修改費用則重算本機報酬，都不必上網下載。
更新資料期間或母池規則必須明確登錄新版，不與舊版績效混用。
既有 GitHub Actions 與斷點備份保留，新資料任務預設只準備資料，不做策略搜尋。
網頁不需持續顧著，但 Cloud 主機重啟或磁碟遺失仍須還原檢查點。
本版沒有新的真實市場獲利驗證，不自動下單。
